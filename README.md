# 🌻 Sunbird AI — Speak & Translate

A Generative AI web app that takes English text or audio, summarises it, translates the summary into a Ugandan local language (Luganda, Acholi, Ateso, Runyankole, or Lugbara), and reads it aloud.

Powered end-to-end by [Sunbird AI's APIs](https://docs.sunbird.ai) — STT, the Sunflower LLM, and Sunbird's TTS voices.
